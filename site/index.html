MODE

Public address only. Paste a seed phrase or private key and GHOST wipes it and refuses to send it.

What happens to an address I paste?

Sample mode never leaves your browser. In live mode the address goes to GHOST's API, which asks Helius for the latest page of public transactions and returns counts. GHOST's code never writes your address or IP to its logs (Cloudflare, which hosts it, keeps standard request logs). Results are cached for 5 minutes under a scrambled key to save credits, and share links and cards never contain the address.
